# Incident Postmortem: INC-001

## Incident Summary
* **Date:** 2026-08-14
* **Authors:** TillStream Engineering Team
* **Status:** Resolved
* **Impact:** 100% loss of throughput on the POS event stream for approximately 3 minutes. Total downtime. No data loss occurred due to producer buffering.

## Leadup
The TillStream platform was operating at steady state. A single Kafka broker was processing a highly skewed multi-tenant workload generated by the Go producer service, and being consumed by a downstream Python consumer.

## Fault
At approximately 07:50 UTC, the primary (and only) Kafka broker suffered a simulated catastrophic hardware failure (hard kill).

## Impact
1. **Producer Resilience:** The Go producer immediately lost connection to the cluster. Due to standard resilient configurations, the producer did not crash; instead, it began aggressively buffering generated events in memory.
2. **Consumer Starvation:** The Python consumer lost its data feed. Processing dropped to 0 events per second.
3. **Observability:** Grafana dashboards correctly reflected the outage. Broker health metrics vanished, throughput lines flatlined to zero, and the system entered a critical state.

## Detection
The outage was detected instantly via the Prometheus/Grafana observability stack, specifically the "Kafka Exporter Overview" dashboard. 

## Remediation / Recovery
At 07:56 UTC, the broker was restarted (simulating a hardware replacement and daemon restart). 
Within seconds:
1. The KRaft controller re-established the cluster state.
2. The Go producer successfully re-established its TCP connection and immediately flushed its in-memory buffer.
3. The Python consumer picked up exactly where it left off, successfully processing the backlog and draining the accumulated lag.

## Action Items
* **Add Replica Brokers:** A single-broker cluster is a single point of failure. Future sprint plans must include horizontally scaling to a minimum 3-broker cluster with `replication.factor=3` to ensure high availability during individual node failures.
